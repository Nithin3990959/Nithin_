# C Nithin — Portfolio

A responsive personal portfolio built with HTML, CSS, and vanilla JavaScript.

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Open this repository's **Settings**.
2. Select **Pages** in the left sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then click **Save**.
5. Wait for the Pages deployment to finish.

The expected project-site URL is:
https://nithin3990959.github.io/Nithin_/
